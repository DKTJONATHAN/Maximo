Privacy Policy

Effective date: 26 November 2026 · Last updated: 26 November 2026

This policy explains how MAXIMO handles Google user data when its account owner connects Google Search Console. MAXIMO is an owner-operated analytics utility maintained by Jonathan Mwaniki. It is not a public multi-user analytics service.

1. Information MAXIMO accesses

When authorized, MAXIMO uses the Google OAuth scope https://www.googleapis.com/auth/webmasters.readonly. Through the Google Search Console API it accesses:

  • The list of Search Console properties available to the authorizing Google account.
  • Web search performance rows for those properties, including search queries, page URLs, clicks, impressions, click-through rate, average position and the requested date range.

MAXIMO does not request access to Gmail, Google Drive, contacts, calendars, Google Ads, or the ability to modify Search Console settings or data.

2. How Google data is used

Search Console data is used only to generate analytics for the account owner: question-query discovery, query-to-page attribution, position-group click-through-rate comparisons, and CSV/JSON reports. These outputs help the owner review content and search-performance opportunities.

MAXIMO does not sell Google user data, use it for advertising or ad targeting, use it for credit or lending decisions, or transfer it to data brokers. It does not use the data for purposes unrelated to the features described on the MAXIMO homepage.

3. Processing, storage and service providers

Collection runs in GitHub Actions for the MAXIMO repository. Google data is transmitted to the collector over Google's HTTPS API and processed by the workflow to create reports. The workflow uploads CSV, JSON and Markdown report files as GitHub Actions artifacts retained for 30 days. Because this repository is public, these artifacts are publicly downloadable by anyone with access to the repository.

MAXIMO also publishes a website command-centre dashboard at dashboard.html. Its current snapshot includes property identifiers/hosts, aggregate clicks and impressions, comparison changes, sitemap submission/download dates and counts, sitemap warnings/errors, and a small sample of inspected page URLs with Google indexing verdicts and canonical/crawl information. Submission history for Google sitemaps and IndexNow is also published. The dashboard snapshot is committed to the public repository; prior snapshots may remain in Git history even after the current file is replaced. Do not connect confidential client properties or third-party data to this public workflow. For confidential reporting, use a private repository and private hosting/storage before connecting those properties.

The standard collector uses the read-only Search Console OAuth scope. A separate, optional sitemap-submission workflow can use a dedicated Google OAuth grant with the broader webmasters scope, stored in separate GitHub Actions secrets. The optional IndexNow workflow uses a site-specific IndexNow key stored as a GitHub Actions secret and sends only the URLs explicitly supplied to that workflow.

The owner may separately configure Google Cloud Storage (GCS) archival. If enabled, report files are copied to the owner's configured bucket. The owner controls that bucket, its access permissions and any retention or deletion lifecycle rules. GCS archival is optional and is not enabled merely by authorizing Search Console.

OAuth client credentials and the refresh token are stored as GitHub Actions repository secrets and used by the workflow to obtain short-lived access tokens. Tokens are not intended to be written to reports or workflow logs. GitHub and Google provide the infrastructure needed to host the repository/workflow and deliver the requested API service, respectively; their own privacy and security terms also apply.

4. Sharing and human access

Source code, documentation, workflow definitions and report artifacts are publicly readable/downloadable because the repository is public. Artifacts expire automatically after 30 days. The owner is responsible for ensuring that every connected Search Console property is appropriate for public disclosure. For confidential data, use a private repository or a private Google Cloud Storage bucket with restrictive IAM permissions.

Data is not otherwise disclosed to third parties except as necessary to operate the Google API, GitHub Actions and any owner-enabled GCS storage, to protect the service, or where disclosure is required by law.

5. Retention

  • GitHub reports: workflow artifacts are configured for 30-day retention and then expire automatically, unless deleted earlier.
  • Public dashboard and submission history: the latest JSON snapshot and submission logs are stored in the public repository and may remain in Git history indefinitely.
  • Optional GCS reports: retained until the owner deletes them or a bucket lifecycle/retention rule removes them.
  • OAuth secrets: remain in GitHub Actions secrets until the owner replaces or deletes them, or revokes the OAuth grant.
  • Google source data: remains subject to Google's own retention and product policies in Search Console.

6. Security

MAXIMO requests read-only Search Console access and uses GitHub Actions secrets for OAuth credentials. The test job has read-only repository permissions. The trusted collection job receives GitHub OIDC permission only when it runs outside pull requests; optional GCS access uses Workload Identity Federation rather than a service-account key. No service-account private key is required for the optional GCS integration. The owner should protect their Google and GitHub accounts with strong authentication and review repository collaborators and cloud-storage permissions regularly.

7. Your choices and deleting data

The account owner can stop future access by revoking MAXIMO's access in Google Account connections, then deleting the GSC_CLIENT_ID, GSC_CLIENT_SECRET and GSC_REFRESH_TOKEN repository secrets in GitHub. The owner can delete generated workflow artifacts from the repository's Actions area and delete any archived report objects from the configured GCS bucket. Removing the OAuth grant does not automatically delete previously generated reports; those must be deleted from their storage locations.

For privacy questions or a deletion request relating to MAXIMO, contact jonathanmwaniki07@gmail.com.

8. Children's privacy

MAXIMO is not designed for children and is not directed to children under 13. It is an owner-operated technical analytics utility.
