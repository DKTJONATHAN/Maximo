# MAXIMO — Engineering Intelligence System

**Build useful software. Reject generic output. Verify every claim. Ship safely.**

MAXIMO is a modular software-engineering agent platform and specialist skills library for production web development. It inspects repositories, plans minimal changes, implements frontend/backend work, audits security and UX, runs tests, diagnoses failures, and verifies outcomes.

## Mission
- Build production web apps across React, Next.js, TypeScript and other stacks.
- Enforce distinctive, product-specific UI/UX instead of generic AI layouts.
- Find and fix bugs with regression tests.
- Apply secure-by-default engineering and authorized security testing.
- Integrate databases, APIs, Supabase, GitHub, CI/CD, analytics and SEO.
- Reuse specialist skills and project knowledge efficiently.

## Principles
- Inspect before changing; preserve working behavior.
- Prefer deterministic tools and small patches over unconstrained agent loops.
- Use least privilege, explicit approvals and isolated execution.
- Load skills on demand.
- Never claim success without observable evidence.
- Require human review for production deploys, destructive operations, permission changes and active security testing.

## Status
Initial foundation and skills are being established. The agent runtime, sandboxed execution, approval gates, persistence and end-to-end evaluations are not yet implemented. No autonomous production deployment is enabled.
